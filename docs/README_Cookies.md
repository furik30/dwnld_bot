# Настройка Cookies для обхода ограничений 🍪

Для того чтобы бот мог скачивать видео с ограничениями (например, 18+ на YouTube) или контент из закрытых/защищенных разделов Instagram и TikTok, необходимо предоставить боту файлы куки (cookies) в формате **Netscape**.

## 1. Установка расширения

Для удобного экспорта мы рекомендуем использовать расширение **Cookie-Editor**:

- [Для Chrome / Edge / Brave](https://chromewebstore.google.com/detail/cookie-editor/hlkenndednhfkekhgcdicdfddnkalmdm "null")
    
- [Для Firefox](https://addons.mozilla.org/en-US/firefox/addon/cookie-editor/ "null")
    

## 2. Как получить куки

Повторите эти шаги для каждого сервиса (**YouTube**, **Instagram**, **TikTok**):

1. Зайдите на сайт (например, `youtube.com`) и убедитесь, что вы **авторизованы** в своем аккаунте.
    
2. Нажмите на иконку расширения **Cookie-Editor** на панели браузера.
    
3. В нижней части окна расширения нажмите кнопку **Export**.
    
4. Выберите формат **Netscape**. Текст будет скопирован в буфер обмена.
    
5. Создайте на компьютере текстовый файл и вставьте туда содержимое буфера.
    

## 3. Правильные названия файлов

Бот ожидает файлы с конкретными именами. Сохраните полученные данные в следующие файлы:

- Для YouTube: `youtube_cookies.txt`
    
- Для Instagram: `instagram_cookies.txt`
    
- Для TikTok: `tiktok_cookies.txt`
    

## 4. Размещение файлов

1. Скопируйте созданные `.txt` файлы на ваш сервер в папку проекта: `~/downloader/bot/cookies/` (путь может отличаться в зависимости от места установки).
    
2. Если вы используете Docker, убедитесь, что папка `cookies` примонтирована в `docker-compose.yml`.
    
3. Перезапустите бота, чтобы применить изменения:
    
    ```
    downloader restart
    ```
    

## ⚠️ Важные советы:

- **Безопасность:** Никогда не передавайте файлы куки третьим лицам. Они содержат данные вашей сессии и позволяют войти в ваш аккаунт без пароля.
    
- **Срок действия:** Куки имеют свойство "протухать" (истекать). Если бот снова начал выдавать ошибки авторизации, просто обновите файлы свежими данными из браузера.
    
- **Лог-аут:** Если вы нажмете "Выйти" (Log out) на сайте в браузере, старые куки сразу перестанут работать. Просто закройте вкладку, не выходя из аккаунта.
